## 研究问题

**同一时点，不同永续合约的订单流、成交活动和持仓拥挤程度，能否帮助预测未来 24 小时的相对收益排名？**

本项目研究横截面相对收益：每天为可交易合约形成分数，做多高分组、做空低分组，并把 Funding、换手与交易成本纳入组合核算。研究候选库包含 91 个特征；组合以 Top/Bottom 20% 为目标分组。

公开版提供研究展示与通用回测组件。原始数据、因子构造实现、训练管线和精选表达式保留在私有研究环境中。[公开范围](docs/PUBLIC_SCOPE.md)

## 1. 因子构造与经济逻辑

### 为什么研究永续合约？

永续合约提供连续交易的价格与成交信息，也提供 Funding、永续—现货基差等持仓维度。主动买入成交额能描述买方主动交易的强弱；小时数据则保留日线收盘价没有表达的路径和时段信息。

| 因子家族 | 经济含义 | 主要检验的问题 |
| :--- | :--- | :--- |
| 订单流与主动成交 | 买卖压力、方向持续性 | 交易压力是否已经被价格吸收？ |
| 动量与反转 | 趋势延续、短期价格冲击 | 最近的涨跌延续还是回归？ |
| Funding 与 Basis | 杠杆需求、拥挤与持仓成本 | 拥挤带来溢价还是反转？ |
| 成交与流动性 | 市场关注、交易摩擦 | 收益是否只是流动性补偿？ |
| 波动率 | 总风险与特质风险 | 风险与后续相对收益有何关系？ |
| 市场 Beta | 共同市场暴露 | 信号是否独立于市场方向？ |
| 高阶矩与跳跃 | 偏度、极值、非连续变化 | 尾部风险如何被定价？ |
| K 线路径 | 实体、影线、收盘位置 | OHLC 路径是否具有增量信息？ |
| 日内时段 | 不同 UTC 时段的收益与交易活动 | 24/7 市场是否存在稳定的时段差异？ |

### 从共线性到增量信息

相近因子可能重复表达同一类信息。研究通过相关性与 VIF 诊断、训练期锚点选择、逐期横截面残差化及协方差收缩，区分重复暴露和增量信号。具体配方、变换顺序与参数保留私有。

## 2. 回测框架与单因子结果

### 先明确交易时钟

| 环节 | 统一约定 |
| :--- | :--- |
| 特征输入 | UTC 日 t 的完整 24 根小时 K 线 |
| 信号可用 | t+1 00:00，最后一根输入已结束 |
| 默认入场 | t+1 01:00，预留一小时执行延迟 |
| 持有与退出 | 精确时间戳匹配的 24 小时窗口 |
| 交易池 | 只使用信号时点已知的历史状态与数据 |
| 组合权重 | 反波动率配置、单名硬上限、等额多空腿 |
| 换手 | 新目标权重减去按价格与账户净值漂移后的持仓 |
| 收益归因 | 价格、Funding、佣金、半价差、滑点与冲击分项 |

组合首先确定入选标的，再读取未来收益。已入选标的缺失退出价或 Funding 数据时默认报错，不能通过删除标的改善结果。正 Funding 对多头是支付，对空头是收入；按实际持仓窗口逐事件计入。

```text
组合净收益 = 价格贡献 + Funding 贡献 − 交易成本
实际换手 = Σ |新目标权重 − 漂移后的交易前权重|
```

公开代码提供时间对齐、数据完整性、权重约束、Funding 覆盖、成本与账本组件。它是日频线性名义本金核算模型；交易所订单、日内保证金与强平模拟属于另外的执行层。[完整框架说明](docs/FRAMEWORK.md)

### 单因子研究展示

以下为演示材料中的精选结果：**2024 年 1 月至 2026 年 2 月评价窗口，2 bps 交易成本**。

| 信号 | CAGR | Sharpe | 最大回撤 | 日均换手 |
| :--- | ---: | ---: | ---: | ---: |
| 日内收益偏度 | 25.4% | 1.45 | −11.1% | 1.57 |
| 三日反转 | 11.8% | 0.76 | −14.4% | 0.36 |
| 中间时段收益 | 16.1% | 0.74 | −22.0% | 1.60 |
| 上影线比例 | 8.3% | 0.56 | −28.3% | 1.55 |
| 24 小时反转 | 3.0% | 0.24 | −27.1% | 1.59 |
| 主动买入不平衡波动 | 3.1% | 0.26 | −22.8% | 0.95 |
| 永续—现货基差 | 1.0% | 0.14 | −15.7% | 1.36 |
| Amihud 价格冲击 | 0.3% | 0.12 | −25.5% | 0.79 |

*来源：研究演示材料单因子部分。换手表示相对于账户权益的交易总名义本金。原始观测、每日净值与持仓序列不随公开版分发。*

这组结果同时呈现预测效果、风险和交易强度。较高换手需要更强的收益优势抵消成本；经济逻辑合理也不意味着组合一定有效。

## 3. 机器学习组合

### 在同一框架中比较模型

演示材料以 **2020–2023 年为训练期，2024 年 1 月至 2026 年 2 月为评价期**，采用横截面预处理与滚动训练。各方法输出合约分数，再进入同一组合核算框架。

| 方法 | 核心思路 | 优点 | 主要限制 |
| :--- | :--- | :--- | :--- |
| 滚动 IC 加权 | 用已经成熟的历史 RankIC 配置因子权重 | 透明、易解释 | 依赖 IC 稳定性 |
| Lasso | 稀疏线性监督学习 | 正则化与变量筛选 | 难以表达复杂非线性 |
| LightGBM / GBM | 梯度提升树学习非线性映射 | 可表达交互和条件关系 | 模型复杂度与过拟合风险更高 |

| 演示材料中的模型 | CAGR | Sharpe |
| :--- | ---: | ---: |
| 滚动 IC 组合 | −4.5% | −0.28 |
| Lasso 组合 | 4.6% | 0.41 |
| GBM 组合 | 18.4% | 1.36 |
| 正交订单流参考信号 | 26.0% | 1.77 |
| 参考复合信号 | 17.8% | 1.35 |

*来源：演示材料“ML Portfolio – Combine”。保留不同方法的完整比较，包括较弱的基准。*

### 遗传规划：发现候选表达式

遗传规划使用算术、排序与非线性算子生成候选表达式，在训练期以平均横截面 RankIC 或多空 Sharpe 为目标，再按相关性去重并保留前五个候选，最后进入独立评价阶段。精选符号候选在演示材料中报告 **40.4% CAGR、2.59 Sharpe**。

表达式、搜索实现和研究产物保留私有；公开内核可以接收外部生成的任意评分面板。模型方向、超参数、特征选择和表达式搜索都应在训练窗口内完成，滚动训练只使用已经成熟的标签。
