# Public release scope

This repository contains selected general-purpose backtesting components and a research overview by RONG Jia.

| Included | Retained privately |
| :--- | :--- |
| Timestamp alignment and completeness helpers | Original market datasets and derived panels |
| Portfolio allocation and PnL accounting | Factor construction library and tuned transformations |
| Funding and cost attribution | Model training pipelines and fitted model artifacts |
| Generated example and regression tests | Symbolic-search implementation and selected expressions |
| Methodology diagrams, selected presentation charts and summaries | Research notebooks, database configuration, complete slides |

The generated example demonstrates the accounting API. It does not reproduce the research signals or results. This release has its own Git history; it does not import the private repository's history.

The README's numerical summaries and selected graphics describe presentation experiments. Underlying observations, positions and daily NAV series are not distributed. Chart images are publicly viewable and downloadable; keeping the underlying dataset private does not make a published graphic confidential.
